# pomodoro-extension

chrome extension with retro theme!

clicking the button opens the timer with focus and break cycles, a mini progress timeline, and a draggable and resizeable popup

made using js, css, json.

how to install:
1. open chrome and go to chrome://extensions
2. turn on developer mode
3. click "load unpacked"
4. upload folder with all of the files here within it
5. refresh any open tab or open a new one. you'll know it worked if a tomato button pops up in the right bottom corner

how to use:
1. click tomato button to open
2. click "start" to begin 25-minute focus session
3. click "pause" any time to stop countdown without losing your place
4. click "finish" to start next phase early
5. click "reset" to go back to very first phase of the cycle
- drag tomato button by itself to move the whole widget anywhere on the page
- drag the small black square in the popup's top-left corner to resize the popup. everything should scale with it
